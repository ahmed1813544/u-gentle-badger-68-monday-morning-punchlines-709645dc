## What it does

`main.py` (Python 3.13 standard library only, no third-party imports) writes
exactly one original joke about Monday mornings — at most 200 characters —
to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).

The joke:

> Monday morning is the only time I envy my phone: it gets charged overnight and wakes up at 100%.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: every run writes the same bytes.
